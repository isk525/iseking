Windows便利機能５選

全部標準機能。まずは一つだけでも試してみてほしい話

📅 公開日：2026.09.09 ⏱ 読了目安：6分

この記事で分かること

  • 過去にコピーした内容を呼び出す方法
  • 画面の必要な部分だけをすぐ撮る方法
  • キーボードからアプリを素早く起動する方法
  • よく使う場所やアプリへ早くたどり着く工夫
  • 作業ごとにデスクトップを分ける方法

こんにちは、イセキングです。

毎日パソコンを使いよると、「この操作、もうちょっと早くできんかな？」と思うことありますよね。DXや業務改善というと、新しいシステムを入れたり、便利なソフトを追加したりするイメージがあるかもしれませんが、Windowsに最初から入っとる機能を使うだけでも、かなり楽になります。

今回は、僕が普段よく使っているWindowsの標準機能を5つ紹介します。

※この記事では、「Win」というキーがよく出てきます。
　Winキーとは、キーボード左下にあるWindowsのロゴが付いたキーのことです。
　場所だけ覚えておけば、本記事もスムーズに見ていただけるかと思います。

特別なソフトは不要です。
「これ便利そう」と思ったものを持ち帰ってください。

① Win + V｜クリップボード履歴

最初に紹介したいのが、Win + Vです。

普通のCtrl + Vでは、最後にコピーした内容を貼り付けます。
Win + Vを使うと、クリップボードの履歴を開いて、少し前にコピーした内容も選べます。

例えば、別の画面から次の情報を順番に移したいとします。

  • 自治体名
  • 担当者名
  • 電話番号
  • メールアドレス

一つコピーして、一つ貼り付けて、また元の画面へ戻る。これを繰り返すのは、地味に面倒です。
先に必要な内容を全部コピーしておけば、貼り付ける画面でWin+Vを押して、履歴から選べます。

「さっきコピーしたやつ」へ
すぐ戻れる

初めて使うときは、Win + Vを押してクリップボード履歴を有効にしておく必要があります。
今回の5つの中で、最初に一つだけ試すなら、僕はこれをおすすめしますね。

※クリップボード履歴は最大25件まで保存されます。
古い項目から自動的に削除されますが、 残しておきたい項目はピン留めできます。
また、パソコンを再起動すると、 ピン留めしていない履歴は消えます。

② Win + Shift + S｜必要なところだけ画面キャプチャ

次は、Win + Shift + Sです。

このショートカットを押すと、画面の必要な範囲を選んでキャプチャできます。撮った画像はクリップボードへ入るので、そのままチャットやPowerPointなどへ貼り付けられます。

特に便利なのが、操作方法やエラー画面を誰かに伝えたいときです。

  • 問い合わせで画面の状態を共有する
  • 手順書へ操作画面を載せる
  • 資料へ画面イメージを貼る
  • 修正してほしい場所を伝える

文章だけで説明すると長くなることも、画面を一枚貼ればすぐ伝わります。

「うまく説明できん」と思ったら、まず画面を撮って見せる。
これだけで、やり取りがかなり楽になります。

③ Win + R｜ファイル名を指定して実行

Win + Rを押すと、「ファイル名を指定して実行」が開きます。

ここへコマンドを入力すると、アプリや設定画面をキーボードから直接開けます。

  • calc：電卓を開く
  • notepad：メモ帳を開く
  • control：コントロールパネルを開く

最初は「スタートメニューから開けばよくない？」と思うかもしれません。

でも、よく使うコマンドを覚えると、マウスで探すより早い。
キーボードから手を離さず開けるのもいいところです。

Win + Rは、環境変数と組み合わせると、自分専用の呼び出し方まで作れます。この話は、次の記事で詳しく紹介したいと思います。

④ クイックアクセスとタスクバーへピン留め

ショートカットキーではありませんが、毎日使う場所をピン留めしておくのもかなり効果的です。
例えば、仕事で何度も開くフォルダを毎回エクスプローラーを開いて、フォルダを何階層もたどるのは面倒です。

そんなときはピン留めしておくだけで、ワンクリックで開くことができます。

  • フォルダ → 右クリック → クイックアクセスにピン留め
  • アプリ → 右クリック → タスクバーにピン留め

入り口を目に見える場所へ固定しておくだけで、「どこにあったっけ？」が減ります。

1回の差は数秒でも、毎日何度も開く場所なら効果は大きい。地味ですが、こういう改善が一番長く効きます。

⑤ 仮想デスクトップ｜作業場所を丸ごと分ける

最後は、仮想デスクトップです。

仮想という単語を聞くと少し身構えてしまうかもしれませんが
仮想デスクトップは、Windowsの中に複数の作業スペースを作れる機能です。

新しいデスクトップを作るときはWin + Ctrl + D。
作ったデスクトップは、Win + Ctrl + ← または → で切り替えられます。

例えば、こんなふうに分けられます。

  • デスクトップ1：普段の仕事
  • デスクトップ2：会議と共有資料
  • デスクトップ3：調査や情報収集
  • デスクトップ4：個人作業

一つのデスクトップで全部開くと、ブラウザもExcelも資料も混ざって、必要な画面がどこにあるか分からんなります。仮想デスクトップで作業ごとに分けると、画面を探す時間が減るし、会議中に関係ない画面を見せてしまう心配も減らせます。

作業ごとに
机を丸ごと切り替える感覚

最初は「そんなにデスクトップ要らんだろ」と思うかもしれません。
でも、一度使い始めると、全部のウィンドウを一つの場所に置いとった頃には戻りにくい。
僕にとっては、今ではないと困る機能の一つです。

おわりに

今回紹介したのは、どれもWindowsの標準機能です。

01Win + V
02Win + Shift + S
03Win + R
04ピン留め
05仮想デスクトップ

新しいツールを入れなくても、今ある機能を知るだけで仕事が楽になることはあります。
全部を一気に覚える必要はありません。

まずは
Win + Vから

一つ使ってみて、便利やったら続ける。合わなかったら、別の機能を試してみる。
それぐらいの気軽さでいいと思います。
