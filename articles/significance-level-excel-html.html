機関投資家から学んだ「有意水準」とは？
Excelでの検証とHTMLで作る簡易Webツール

どうも、イセキングです。

先日、同僚の奥さんと話す機会がありました。
銀行で機関投資家として働かれているらしく、普段から統計学を駆使して運用されているとのこと。
話を聞いていると「有意水準」やら「確率論」やら専門用語が飛び交って、正直なところ最初は「頭が良すぎて何言よるか分からん…！」となりました（笑）。

でも、自分なりに噛み砕いて調べてみると、これは金融のプロだけでなく、僕たちが日頃やっている業務改善やA/Bテスト、データの効果測定にもめちゃくちゃ使える考え方だと分かったんです。

そもそも機関投資家とは？何が求められる仕事？

機関投資家というのは、個人の資産ではなく、顧客から預かった莫大な資金を運用するプロのことです。
勘や度胸で「なんとなく上がりそうだから」と投資するわけにはいかず、常に客観的で納得感のある根拠が求められます。

その根拠を示すために使われているのが、統計学によるデータ分析です。
中でも重要なテーマが「その結果は、たまたまなのか？それとも必然なのか？」を見極めることです。

「有意水準（p値）」って何？

ここで登場するのが「有意水準」という考え方です。
難しく言えば仮説検定の基準ですが、ざっくり言うと「偶然起きた確率（p値）がどれくらいあるか」を調べる指標です。

  • 例えば、新しい業務手順に変えたら作業時間が5分縮んだとします。
  • これが「たまたまその日の調子が良かっただけ（偶然）」なのか。
  • それとも「手順を変えた効果が明確にあった（必然）」のか。

統計学では、この偶然起きる確率（p値）が「5%（0.05）未満」であれば、「偶然ではなく、意味のある差（有意な差）がある」と判断するのが一般的なルールになっています。

「たまたまのブレ」に振り回されず、「明確な効果があったか」を数字で客観的に判定するのが有意水準の役割です。

Excelなら関数ひとつで出せる

この有意水準（p値）の検証ですが、Excelなら非常に簡単に計算できます。
変更前のデータ群と、変更後のデータ群を用意して、以下の関数を入力するだけです。

=T.TEST(変更前の範囲, 変更後の範囲, 2, 2)

これで算出された数字が「0.05」より小さければ、「統計的に意味のある変化だった」と言えます。

HTMLとJavaScriptなら、ブラウザで動くツールにできる

Excelも便利ですが、「チームに共有したい」「ブラウザ上でサクッと入力して判定したい」というときは、やっぱりHTMLとJavaScriptでWebアプリにしてしまうのが一番手軽です。

実際に、2つのデータ群を入力したら平均値の差とp値を計算して簡易判定するツールを組み込んでみました。

【体験版】簡易・有意差（t検定）チェッカー

※カンマ（,）区切りで数値を入力してください

ここに判定結果が表示されます。

このツールのHTML/JSコード（全コード）

このツールは、特別なライブラリを使わずHTML1ファイルだけで作ることができます。
コードをパソコンに保存してブラウザで開くだけで、いつでも使えます。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>簡易有意差チェッカー</title>
  <style>
    body { font-family: sans-serif; padding: 20px; max-width: 600px; margin: auto; }
    textarea { width: 100%; height: 60px; margin-bottom: 10px; }
    button { background: #f97316; color: #fff; border: none; padding: 10px 20px; cursor: pointer; border-radius: 4px; }
    .result { margin-top: 15px; padding: 10px; background: #e0f2fe; border-radius: 4px; }
  </style>
</head>
<body>
  <h2>簡易・有意差（t検定）チェッカー</h2>
  <label>グループA（カンマ区切り）:</label>
  <textarea id="a">10, 12, 11, 13, 10, 11</textarea>
  <label>グループB（カンマ区切り）:</label>
  <textarea id="b">15, 14, 16, 13, 15, 14</textarea>
  <button onclick="calc()">判定する</button>
  <div id="res" class="result">結果がここに表示されます</div>

  <script>
    function calc() {
      const parse = id => document.getElementById(id).value.split(',').map(Number).filter(n => !isNaN(n));
      const A = parse('a'), B = parse('b');
      if (!A.length || !B.length) return alert('数値を入れてください');

      const mean = arr => arr.reduce((a, b) => a + b, 0) / arr.length;
      const mA = mean(A), mB = mean(B);

      // 簡易ウェルチのt検定計算
      const stat = arr => {
        const m = mean(arr);
        return arr.reduce((a, b) => a + Math.pow(b - m, 2), 0) / (arr.length - 1);
      };
      const vA = stat(A), vB = stat(B);
      const se = Math.sqrt((vA / A.length) + (vB / B.length));
      const t = Math.abs(mA - mB) / se;

      // 自由度の簡易計算とt値の基準判定（概算）
      const isSignificant = t > 2.1; 

      document.getElementById('res').innerHTML = 
        `<b>平均A:</b> ${mA.toFixed(2)} | <b>平均B:</b> ${mB.toFixed(2)}<br>` +
        `<b>判定:</b> ${isSignificant ? '【有意差あり】偶然ではなく効果があった可能性が高いです！' : '【有意差なし】たまたまの誤差の範囲内かもしれません。'}`;
    }
  </script>
</body>
</html>

機関投資家以外でも使える横展開のアイデア

この「たまたまか、必然か」を調べるアプローチは、仕事のあらゆる場面で活用できます。

  • Webマーケティング：A/Bテストで新しいボタンデザインにした際、クリック率の上昇がたまたまじゃないかを検証。
  • 業務改善：マニュアルを改定した前後で作業時間を測定し、本当に業務効率化できたかを証明する。
  • 日常・趣味：ゴルフのフォームを変えて練習したとき、スコアの良さが「たまたまの調子」か「上達」かを確かめる。

おわりに

最初は「難しそうな話」として聞いた話でしたが、自分が使いやすいツールに落とし込んでみると、すごく身近で役立つ知識に変わりました。

Excelで計算してみるのも良し、HTMLでサクッと自分専用のチェッカーを作ってみるのも良し。
これからも難しい概念を「使えるツール」にしながら、楽しく業務改善をしていきたいと思います！
