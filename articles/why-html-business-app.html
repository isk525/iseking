Webアプリ作成

なぜ私はHTMLで
業務アプリを作るのか

ノーコードでもExcelでもなく、HTMLを選ぶ理由

📅 公開日：2026.09.08 ⏱ 読了目安：5分

この記事で分かること

  • 私がHTMLで業務アプリを作る理由
  • Excelやノーコードツールとの違い
  • GitHub Pagesを活用するメリット
  • 小さく作り、改善を繰り返す考え方

こんにちは、イセキングです。

私は業務改善や自治体DXに関わる中で、さまざまなツールやサービスを試してきました。

Excel、Access、kintone、Power Apps、各種ノーコードツールなど、便利な選択肢はたくさんあります。

そんな中で、最近私が最も多く使っているのは「HTML・CSS・JavaScript」を使ったシンプルなWebアプリです。

「なぜわざわざHTMLで作るのか？」

今回はその理由を紹介したいと思います。

業務改善を進めると、必ず「ちょっとした困りごと」に出会う

業務改善というと、大掛かりなシステム導入をイメージされるかもしれません。

しかし実際は、次のような小さな困りごとの積み重ねです。

  • この入力をもう少し楽にしたい
  • 集計を自動化したい
  • メモを共有したい
  • 一覧で見られるようにしたい

こうした課題のために、大規模なシステムを導入するのは現実的ではありません。だからこそ、素早く試せる仕組みが必要になります。

Excelは便利。でも限界もある

もちろんExcelは非常に優れたツールです。私自身、関数やマクロを活用して多くの改善を行ってきました。

一方で、業務の内容によっては次のような課題もあります。

  • スマホでは使いづらい
  • 入力フォームが作りにくい
  • 複数人での利用が難しい
  • 機能を増やすほどUIが複雑になりやすい

業務が複雑になるほど、Excelだけでは対応しきれない場面が増えてきます。

ノーコードツールも便利。でも万能ではない

最近は、ノーコード・ローコードツールも非常に充実しています。短時間でアプリを作れることは大きな魅力です。

ただし、利用環境によっては次のような制約があります。

  • 利用料が発生する
  • 組織内で契約や利用許可が必要になる
  • 細かなカスタマイズが難しい
  • 特定のサービスへの依存度が高くなる

便利だからこそ、そのツールのルールに合わせて業務を変える必要が出てくることもあります。

HTMLは、必要なものだけを小さく作り、使いながら改善するサイクルを速く回せる。私にとって、そこが一番の魅力です。

HTMLなら自由度が高い

HTML・CSS・JavaScriptで作るWebアプリの大きな魅力は、自由度の高さです。

  • 必要な画面だけ作る
  • 必要な項目だけ置く
  • 必要な機能だけ実装する

余計な機能を入れず、自分が本当に使いたい仕組みを作れます。

ブラウザがあれば動く

HTMLで作ったアプリは、基本的にブラウザで動きます。

  • Windows
  • Mac
  • iPhone
  • Android

さまざまな環境で利用でき、インストールせず試せる構成にもできます。「とりあえず使ってみる」までのハードルが低いことも魅力です。

GitHub Pagesで無料公開できる

私がHTMLをよく使う理由の一つが、GitHub Pagesを活用できることです。

個人での学習や小規模な公開であれば、作成したアプリやWebサイトを公開する選択肢になります。実際、このサイトもGitHub Pagesで公開しています。

作ること自体が学びになる

アプリを作っていると、完成した機能だけではなく、さまざまな力が身につきます。

  • 業務を整理する力
  • 課題を分析する力
  • UIを考える力
  • データを扱う力

何を入力し、何を表示し、どう使ってもらうのかを考える過程そのものが、業務を見直す機会になります。

私が作ってきたもの

これまで、個人で次のようなアプリやツールを作ってきました。

  • ゴルフ上達支援アプリ
  • 口コミ管理アプリ
  • 業務改善支援ツール
  • 業務量調査関連ツール

完璧なシステムではありません。それでも、「こんな機能が欲しい」と思ったときに、すぐ試作品を作って検証できることは大きな強みだと感じています。

まずは小さく作る

私は業務改善において、「最初から完璧を目指さない」ことを大切にしています。

STEP 01まずは作る
STEP 02使ってみる
STEP 03改善する

HTMLは、このサイクルを高速で回すための非常に優れた選択肢だと思っています。

おわりに

DXというと、難しく聞こえるかもしれません。

目の前の仕事を
少し楽にすること

私は、それこそがDXの第一歩だと考えています。

HTMLでアプリを作ることは、そのための手段の一つです。

このサイトでは、実際に作ったアプリや、開発の過程で学んだこと、仕事を楽にするためのアイデアを発信していきたいと思います。

同じように「業務をもっと楽にしたい」「自分でツールを作ってみたい」と思っている方にとって、何か一つでもヒントになればうれしいです。
