WEBアプリ作成

なぜ私はHTMLで業務アプリを作るのか

ノーコードでもExcelでもなく、HTMLを選ぶ理由

公開日：2026.09.08

こんにちは、イセキングです。

私は業務改善や自治体DXに関わる中で、さまざまなツールやサービスを試してきました。

Excel、Access、kintone、Power Apps、各種ノーコードツールなど、便利な選択肢はたくさんあります。

そんな中で、最近私が最も多く使っているのは「HTML・CSS・JavaScript」を使ったシンプルなWebアプリです。

「なぜわざわざHTMLで作るのか？」

今回はその理由を紹介したいと思います。

業務改善を進めると、必ず『ちょっとした困りごと』に出会う

業務改善というと大掛かりなシステム導入をイメージされるかもしれません。

しかし実際は、

  • この入力をもう少し楽にしたい
  • 集計を自動化したい
  • メモを共有したい
  • 一覧で見られるようにしたい

といった小さな困りごとの積み重ねです。

Excelは便利。でも限界もある

  • スマホでは使いづらい
  • 入力フォームが作りにくい
  • 複数人利用が難しい
  • UIが複雑になりやすい

ノーコードツールも便利。でも万能ではない

  • 利用料が発生する
  • 組織内の契約が必要
  • 細かなカスタマイズが難しい
  • サービスへの依存がある

HTMLなら自由度が高い

必要な画面だけ作る。 必要な機能だけ作る。 必要なデータだけ扱う。

余計な機能を入れず、自分が本当に使いたい仕組みを作れることが大きな魅力です。

ブラウザがあれば動く

  • Windows
  • Mac
  • iPhone
  • Android

環境を選ばず利用できるため、試しやすいのも魅力です。

GitHub Pagesで無料公開できる

私がHTMLをよく使う理由の一つがこれです。

GitHub Pagesを使えば、作成したアプリやサイトを無料で公開できます。

作ること自体が学びになる

  • 業務を整理する力
  • 課題を分析する力
  • UIを考える力
  • データを扱う力

私が作ってきたもの

  • ゴルフ上達支援アプリ
  • 口コミ管理アプリ
  • 業務改善支援ツール
  • 業務量調査関連ツール

まずは小さく作る

私は業務改善において、 「最初から完璧を目指さない」 ことを大切にしています。

まずは作る。 使ってみる。 改善する。

HTMLは、そのサイクルを高速で回すための非常に優れた選択肢だと思っています。

おわりに

DXというと難しく聞こえるかもしれません。

私は、

目の前の仕事を少し楽にすること

こそがDXの第一歩だと考えています。

このサイトでは、実際に作ったアプリや開発を通して学んだことを発信していきます。
